{{!-- Tab 5: Item Catalog journal --}}

Item Catalog Journal storage

The item catalog can live in a world Journal entry — one page per equipment group, each page a name-keyed JSON object — that the GM edits in-game. When the journal exists it is the catalog's boot source, ahead of the data service and the bundled files. A page that fails to parse aborts the journal source entirely; the catalog falls back rather than loading partial or empty.

Journal: {{#if catalog.journalExists}}{{catalog.journalName}} (present){{else}}not created yet{{/if}}
Items currently loaded: {{catalog.itemCount}}

Workflow: seed once, edit item JSON in the journal's pages, then Reload. Re-seeding overwrites in-journal edits (it asks first). Deleting the journal returns the catalog to the data service.

Player Guide

Generate a player-facing journal that renders every catalog item as an EQ-style item card in markdown — players browse it in the Journal sidebar and can copy/paste the cards.
